# MNIST Digit Agent

Разпознаване на ръкописни цифри с CNN и **AI агент**, който се управлява с команди на естествен
език и работи изцяло на твоя компютър (езиков модел през [Ollama](https://ollama.com), без облак и без API ключ).

- **Модел:** конволюционна мрежа (421 642 параметъра), обучена върху MNIST. **99,38%** точност
  върху 10 000 тестови картинки, които не е виждала (обучена с data augmentation).
- **Приложение (Streamlit):** обучение с live графики, рисуване и разпознаване, анализ на грешките,
  дообучение с твои примери.
- **Агент:** езиков модел избира сам между 7 инструмента и ги вика в цикъл, докато стигне до отговор.

> **Тествано само на:** Ubuntu 24.04 под WSL2, Python 3.12.3, NVIDIA RTX 2050 (4 GB).
> macOS, Windows без WSL и работа само с процесор **не са проверявани**. Би трябвало да работят,
> но не го гарантирам.

## Инсталация

```bash
git clone https://github.com/Iliyan-0512/mnist-digit-agent.git
cd mnist-digit-agent
```

Виртуална среда и библиотеки (Linux, macOS, WSL):

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

На Windows (PowerShell):

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

> На Windows `pip install torch` по подразбиране дава версия **само за процесор**. За NVIDIA видеокарта

## Стартиране

```bash
streamlit run app.py
```

Отвори **http://localhost:8501**. Първото зареждане отнема около 30 секунди (зарежда се PyTorch),
после превключването между режимите е бързо.

Готовият обучен модел `models/best_model.pt` е в репото, затова не е нужно обучение, за да започнеш.

## Режими

| Режим | Какво прави |
|---|---|
| **Training** | Обучава нов модел с live графики. Има бутон Stop и опция за data augmentation. Новият модел се записва отделно, докато не го запазиш |
| **Inference** | Рисуваш цифра с мишката или качваш картинка. Показва предсказание, увереност и предупреждение при ниска увереност. Може да запазиш пример с верния етикет |
| **Analysis** | Confusion matrix, точност по цифри и най-уверените грешки |
| **Fine-tune** | Дообучава модела върху запазените от теб примери и показва точност преди и след. Решението дали да го приемеш е твое |
| **Agent** | Чат с агента (виж по-долу) |

## Агентът

### 1. Инсталирай Ollama и модел

Свали Ollama от [ollama.com/download](https://ollama.com/download), после изтегли модел
(около 1,9 GB):

```bash
ollama pull qwen2.5:3b
```

Моделът трябва да **поддържа инструменти**. Например `gemma3:1b` не ги поддържа и няма да работи.
Модел `qwen2.5:3b` е с лиценз Qwen Research License (за изследователска употреба).
За търговска употреба провери лиценза му.

### 2. Използвай го

Стартирай приложението, избери режим **Agent** и дай цел, например:

- „Разпознай всички картинки и кажи кои са съмнителни."
- „Какво е написано на scan_03.png?"
- „Запази scan_07.png като пример за цифрата 3."
- „Колко примера за дообучение имам запазени?"
- „Колко е точността на текущия модел?"

Агентът работи с картинките от папката **`agent_files/`**. Има 8 демонстрационни; можеш да добавиш свои
(`.png`, `.jpg`). Първата заявка е бавна (до около 105 секунди на моя компютър), защото моделът се
зарежда във видеопаметта; после всяка стъпка е 1–5 секунди.

### 3. Какво може агентът

| Инструмент | Какво прави |
|---|---|
| `list_images` | Имената на картинките в `agent_files/` |
| `classify_all_images` | Разпознава всички с един извик, връща списък на съмнителните |
| `classify_image` | Разпознава една картинка |
| `feedback_status` | Колко запазени примера има по цифри |
| `evaluate_model` | Точност върху 10 000 тестови картинки (около 37 секунди) |
| `save_example` | Запазва картинка като пример с верен етикет (пише в `feedback/`) |
| `fine_tune_model` | Дообучава и връща точност преди и след (пише `models/finetuned_model.pt`) |

### 4. Граници, които са зададени в кода

- Агентът чете **само** от `agent_files/`; опит за `../` се отказва.
- Няма инструмент за **замяна на модела**. Дообученият модел се приема само от човек, от режим Fine-tune.
- Лимит от 15 стъпки на цел.
- Грешка на инструмент се връща на модела като текст, програмата не се срива.
- Интерфейсът показва какво е извикано и какво е върнато. **Вярвай на тези резултати, не на свободния
  текст на малкия модел**: той понякога греши в думите, дори когато данните са верни.

### Къде отива информацията

Всичко е локално. По подразбиране Ollama слуша само на `127.0.0.1:11434`, моделът се изпълнява на твоя
компютър, и заявките не излизат от него. Не съм проверявал самото приложение Ollama за собствена телеметрия.

## Ако нещо не работи

| Проблем | Какво да направиш |
|---|---|
| Режим Agent казва „Ollama не отговаря" | Стартирай Ollama (`ollama serve`) и провери, че отговаря на http://localhost:11434 |
| Казва, че моделът не е изтеглен | `ollama pull qwen2.5:3b` или смени името в страничната лента |
| Грешка „does not support tools" | Избраният модел не поддържа инструменти; ползвай `qwen2.5:3b` |
| Приложението е във WSL, а Ollama е на Windows | `localhost` не се споделя по подразбиране. Най-лесно е Ollama да е вътре в WSL. Или включи `networkingMode=mirrored` в `C:\Users\<ти>\.wslconfig` и изпълни `wsl --shutdown` |
| Много бавно първо зареждане | Нормално е за PyTorch; следващите са бързи |
| Промяна в кода не се вижда | Файловият наблюдател на Streamlit е изключен нарочно (`.streamlit/config.toml`, прави приложението по-бързо в WSL). Рестартирай сървъра |

## Обучение отначало

```bash
python train.py
```

Сваля MNIST (около 64 MB) и обучава 10 епохи с augmentation (около 3 минути на видеокарта). **Внимание:**
презаписва `models/best_model.pt`.

## Структура

```
app.py             Streamlit интерфейс (всички режими)
model.py           CNN архитектурата
train.py           Обучение, оценка, augmentation
trainer.py         Обучение във фонова нишка (за live графиките)
utils.py           Обработка на картинка, предсказване, анализ, графики
feedback.py        Запазване на примери и дообучение
canvas.py          Компонент за рисуване (canvas_component/ е HTML/JS)
agent.py           Цикълът на агента и връзката с Ollama
agent_tools.py     Инструментите на агента
agent_files/       Картинките, с които работи агентът
models/            Обучен модел и история на обучението
```

## Честни ограничения

- Моделът разпознава само цифри 0–9 и **винаги избира цифра**, дори за буква или драсканица. Драсканица
  може да получи 100% увереност. Висока увереност не е гаранция за верност.
- Предупреждението за ниска увереност (под 95%) хваща част от странните входове, но не буквите.
- Тествано е върху MNIST цифри и малко синтетични примери, не върху много истински почерци.
- Малкият езиков модел (3B) избира правилния инструмент за прости цели, но не е тестван за сложни
  многостъпкови. Свободният му текст съдържа грешки.
- Няма автоматични тестове в репото.
